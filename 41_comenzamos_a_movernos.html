1. Nos desplazamos con seguridad

¡Hola! Estoy encantado de volver a estar con todos vosotros y vosotras.

Este reto está relacionado con el movimiento, la seguridad y la robótica.

La semana pasada recibimos la visita de nuestros mayores de la residencia. Vinieron para compartir sus experiencias y durante la visita tuvimos un pequeño percance: una de las personas mayores que venía en silla de ruedas, al maniobrar, no vio un obstáculo que quedaba justo detrás de él y ... Tranquilos, todo quedó un susto.

Después de la charla nos comentaron que sería muy interesante poder acoplar algún sistema robótico que pudiera avisar de los obstáculos, el gran reto será el de evitar posibles accidentes.  Cuando llegues al final de este apasionante camino, descubrirás qué elemento deberás añadir y dónde.

Creo que somos las personas indicadas para solucionar este problema y de camino ayudar a nuestros mayores.

3. Pasamos la ITV

¿La ITV?, nos referimos a la Inspección Técnica de Vehículos.

Nosotros la vamos a realizar pasando el siguiente test al vehículo que aparecía en el vídeo anterior:

  • ¿Habéis sido capaces de detectar el nombre de este vehículo?
  • ¿Os habéis fijado si dispone de elementos luminosos?
  • La seguridad es muy importante, ¿dispone este vehículo de algún elemento de seguridad? ¿Cómo actúa?
  • En cuanto al desplazamiento, ¿cómo se mueve el vehículo del vídeo?
  • Con respecto a vuestro reto, ¿qué relación encontráis con el robot del vídeo?
  • Para terminar, os pido algo de improvisación, ¿os atrevéis a crear una frase con las palabras: desplazamiento, seguridad y robótica?

4. ¿Qué vamos a aprender?

  1. Conocer los componentes de un vehículo inteligente.
  2. Ser capaz de montar tu propio robot.
  3. Valorar la importancia y aplicaciones de los sensores de ultrasonidos.
  4. Utilizar un editor de código escrito.
  5. Crear un programa utilizando el lenguaje Python para controlar un vehículo capaz de detectar obstáculos.
