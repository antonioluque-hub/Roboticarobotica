4.3. Conoce a nuestros tres protagonistas

Os presento un elemento fundamental en nuestro proyecto, gracias a él nuestro vehículo podrá detectar un obstáculo.

Se trata del robot Maqueen.

Os propongo una serie de actividades que os permitirán descubrir más detalles sobre él.

1. Desmontando a Maqueen

Seguro que ya os estáis frotando las manos, a todos nos gusta desmontar cualquier cosa.

Pero antes de empezar, debemos saber qué vamos a necesitar:

  • Preparar nuestro grupo. Sería interesante elegir a un coordinador o coordinadora del grupo.
  • Un robot Maqueen. Vuestro profesor o profesora os debe facilitar uno.
  • Cuaderno de trabajo para tomar nota de aquello que consideréis importante. Si vuestro grupo prefiere, puede hacerlo en el ordenador.
  • Un móvil o la cámara del portátil para capturar imágenes.

La actividad consisten en:

  1. Desarmar el robot en las siguientes partes:
    • El sensor
    • La placa principal. El portapilas no debes quitarlo.
    • Las llantas.
    • Las bandas de rodaduras.
  2. Realizar un informe de todo el proceso y anotarlo:
    • En vuestro cuaderno.
    • Utilizando el ordenador.
    • Utilizando el documento guía que puedes descargar al final de esta actividad en el botón azul Descarga la Tabla.
  3. El informe debe incluir imágenes. Las podéis conseguir:
    • Haciendo vuestros propios dibujos. Recordad que trabajáis en grupo, quizás a alguien se le dé bien dibujar.
    • Utilizando la cámara del móvil. En este caso, deberéis enviar vuestras imágenes al ordenador para poder utilizarlas. Recordad que es muy importante utilizar el móvil con responsabilidad.
    • Usando la propia cámara del portátil.
  4. Además de las imágenes, deberéis incluir una descripción de cada una de las partes. Aquí es muy importante el trabajo en equipo para que no se os escape ningún detalle.
